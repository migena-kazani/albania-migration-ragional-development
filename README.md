# Internal Migration and Regional Development in Albania
### Replication Package

This repository contains the data and Python analysis code supporting the paper
**"Internal Migration and Regional Development in Albania: A Panel Data Analysis of
Regional Inequalities"** (IJITIS, Submission ID 610), minor-revision
version.

All 34 scripts are numbered in the order the corresponding tables and figures
appear in the manuscript (**Tables 1–49, Figures 1–10**); scripts 33–34 are the
confidence-interval scripts added in the third revision. Running them in order
reproduces every computed quantitative result in the paper from the original source
data. Four tables (1, 2, 48, 49) are qualitative/editorial — a literature-gap table,
a methods summary, a cross-specification sign/significance summary, and a
state-of-the-art literature comparison — and are not generated by a script; see
"Qualitative tables" below.

**What changed in this version (third revision):** the manuscript now reports 95%
confidence intervals inside the existing results tables (Tables 8, 9, 10, 14, 15, 17,
18, 19, 27, 31, 34, 37, 38, 41, 42, 45 and the GDP column of Table 48). Two scripts were
added: `33_confidence_intervals_effect_sizes.py` recomputes every interval and the
standardised coefficients from the same data and estimators as the original scripts, and
`34_check_manuscript_intervals.py` compares the recomputed intervals with those printed
in the manuscript. Scripts 01–32 and all table and figure numbers are unchanged, and no
coefficient, standard error or p-value was recalculated or altered.

### Qualitative tables (no script)

- **Table 1** (Research Gaps and Contributions of the Study) and **Table 2** (Methods
  Used in the Study, including its "Dynamic Panel GMM Estimation" row) are narrative
  summary tables compiled by the authors from the literature and from the methods
  actually used; they are not computed from a data file.
- **Table 48** (Summary of the Sign and Statistical Significance of the GDP–Migration
  Relationship Across All Model Specifications) is a synthesis table compiled from the
  results already produced by scripts 02–32; it has no independent script.
- **Table 49** (State-of-the-Art Comparison with Recent Western Balkans Migration and
  Convergence Studies) is a qualitative literature-benchmarking table, not computed
  from data.

### Note on Figure 1

Figure 1 is an original conceptual schematic (three concentric tiers plus a
cumulative-causation feedback loop) illustrating the mechanism that the dynamic-panel
GMM persistence coefficient (Table 14, γ=0.4525) is interpreted as the empirical
counterpart of. `01_figure1_mechanism_diagram.py` draws it with matplotlib; it is
independent of every other script and does not read any data file.

## How to reproduce the analysis

1. Install Python 3.10+ and the required packages:
   ```bash
   pip install -r requirements.txt
   ```
   `09_dynamic_panel_gmm.py` additionally requires `pydynpd` (listed in
   `requirements.txt`), which in turn requires `numpy<2`.
2. Run the scripts **in numerical order** from inside the `scripts/` folder — several
   scripts read intermediate files produced by earlier ones:
   ```bash
   cd scripts
   for f in $(ls *.py | sort -V); do python "$f"; done
   ```
   Or run them individually in order (01, 02, 03, ... 34). `run_all.sh` does this and
   runs script 09 in a separate environment if `PYDYNPD_PYTHON` is set (see below).
3. Results are written to `output/` (JSON/CSV) and `figures/` (PNG). Each script also
   prints its main results to the console.

**Verification of the new GMM script:** `09_dynamic_panel_gmm.py` was run against
`data/panel_gmm.csv` with `pydynpd 0.2.2` / `numpy 1.26.4` and reproduces the
published Table 14 System GMM estimates exactly: γ=0.4525 (SE=0.0386, p<0.001),
GDP β=0.0081 (SE=0.0007, p<0.001), Unemployment β=-0.0009 (p=0.964), 6 instruments,
Hansen χ²(2)=3.23 (p=0.199), AR(1) z=-1.22 (p=0.222), AR(2) z=1.13 (p=0.260).

All 34 scripts were run end-to-end from an empty `output/` and `figures/` folder and
finished without errors.

**Confidence intervals (scripts 33–34).** Each interval is `b ± c × SE`, with the critical
value c taken from the distribution that produces the p-value shown in the same table
(t with the residual degrees of freedom for the OLS, fixed- and random-effects models;
t with 11 degrees of freedom for the cluster-robust pooled OLS of Table 9; the normal
distribution for the Windmeijer-corrected GMM, the maximum-likelihood spatial lag and the
heteroskedasticity-robust national models). Standardised coefficients are
`b × SD(x) / SD(y)`, with within-region standard deviations for fixed effects. GMM
coefficients are in thousand persons per billion ALL; Table 48 multiplies them by 1000.
Script 34 prints every manuscript interval that differs from the recomputed one by more
than rounding. A few manuscript intervals were computed from the rounded coefficient and
standard error shown in the table, so their last digit can differ from the unrounded
value that script 33 reports; script 34 lists these.

**Simulated p-values.** The permutation p-values of Table 26 (Global Moran's I, 999
permutations) vary slightly between runs unless the random seed is fixed; script 18 sets
the seed so that repeated runs give identical output. With seed 239 the script prints
p = 0.162 (net migration) and p = 0.218 (GDP); Table 26 in the manuscript shows 0.173 and
0.208 (z = 0.98 and 0.80), which come from a different random draw. Moran's I values
(0.010 and -0.028) and the conclusion (no significant spatial autocorrelation) do not
depend on the draw.

## Data sources

- **INSTAT** (Institute of Statistics of Albania) — regional net migration, GDP (Gross
  Value Added), unemployment, population, building permits, and household consumption.
  https://www.instat.gov.al
- **World Bank, World Development Indicators** — national-level net migration, GDP per
  capita, unemployment, urban population, remittances, FDI, education expenditure, and
  the Worldwide Governance Indicators used to build the Territorial Capital Index.
  https://databank.worldbank.org/source/world-development-indicators

## Key packages and methods

- pandas, numpy, scipy — data handling and statistics
- statsmodels — OLS, diagnostic tests (VIF, Durbin–Watson, Breusch–Pagan, Jarque–Bera,
  ADF), Granger causality
- linearmodels — panel Fixed-Effects / Random-Effects estimation, Hausman test
- pydynpd — two-step System GMM (Blundell–Bond) and Difference GMM (Arellano–Bond)
  dynamic panel estimation, collapsed instruments, Windmeijer-corrected standard errors
- scikit-learn — k-means and hierarchical clustering, silhouette / Davies–Bouldin
  validation, Principal Component Analysis
- libpysal, esda, spreg — spatial weights matrix, Global Moran's I, Maximum-Likelihood
  Spatial Lag Model
- matplotlib — all figures, including the conceptual Figure 1 schematic
